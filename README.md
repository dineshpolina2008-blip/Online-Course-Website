# SkillSpring – Online Course Website

A responsive static front-end website for exploring online courses. Built with HTML and CSS.

## Files
- `index.html` – page structure and content
- `style.css` – layout, colors, and responsive styling

## Preview locally
Open `index.html` in a web browser.

## Deployment
Enable GitHub Pages in the repository Settings → Pages, choose the `main` branch and `/ (root)` folder, then save. GitHub will provide the live site URL.

## Note
This is a front-end demo. Course links and contact details are sample content; it does not provide real enrollment, payments, accounts, or a backend.
